# 极压图

极压图是一款纯本地运行的批量图片压缩工具。图片只在浏览器内处理，不上传到服务器。

## 功能

- 图片拖入后自动压缩
- 支持 JPG、PNG、WebP
- 可按指定宽高输出
- 可按目标文件大小压缩
- 支持保持比例、填充裁切和防止放大
- 支持单张下载和批量 ZIP 下载

## 使用方法

直接下载并双击打开 `index.html`，然后把图片拖进页面即可使用，无需安装依赖。

## macOS App 打包

`launcher.applescript` 是本地 App 的启动脚本。将它编译为应用后，把 `index.html` 复制到应用包的 `Contents/Resources/图片批量压缩工具.html` 即可。
